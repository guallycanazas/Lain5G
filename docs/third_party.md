# Third Party

The primary notices are in `THIRD_PARTY_NOTICES.md`.

Recognized third-party components:

- Open5GS.
- UERANSIM.
- MongoDB.
- Docker.
- FastAPI, used by the currently implemented backend.
- React, used by the currently implemented frontend.
- Kamailio, used for the minimal 4G IMS.
- srsRAN 4G, used for LTE simulation and USRP setup.
- UHD, used by the USRP image without automatic FPGA updates.
- CoreDNS, used as the lab IMS DNS.
- `herlesupreeth/docker_open5gs`, recognized as a methodological reference, not as a copied base.
