# Lain5G-Lab v1.1.0

Released 2026-07-30.

Lain5G-Lab v1.1.0 makes the supported reviewer path executable from a clean
GNU/Linux machine and makes scenario claims traceable to explicit evidence.

## Highlights

- A clean-machine installer provisions Python, Node.js, Docker Engine, Docker
  Compose, private synthetic scenario configuration, and all ten unique public
  catalog components without compiling images locally.
- The CLI and web application expose a consistent lifecycle for the four public
  profiles, while mutating operations remain an explicit opt-in.
- The operator interface presents an evidence chain for core readiness, S1/NG
  setup, UE registration/session, tunnel assignment, and user-plane traffic.
- Guarded X300/X310 workflows include compact IMS infrastructure while keeping
  RF authorization, finite duration, automatic stop, and emergency stop
  fail-closed.
- Scenario stop scripts close only matching run metadata when 4G and 5G records
  coexist.

## Verification

- Repository gate: 323 backend tests, 51 frontend tests, 78% backend line
  coverage, TypeScript checking, production frontend build, safe Compose
  rendering, profile checks, release metadata, public-result schemas, internal
  links, and sensitive-file controls.
- Clean Ubuntu 24.04 virtual machine: installer completed and downloaded all ten
  catalog components.
- 4G LTE ZMQ simulation: 14/14 checks passed.
- 5G SA UERANSIM simulation: 15/15 checks passed.
- Both simulations were stopped and their scenario-specific metadata was closed.

## Publication Boundary

This GitHub release contains source code, documentation, and sanitized software
simulation summaries. It does not publish container images or claim that the
catalog images were built from this tag. Catalog and Real-IMS images remain
pull-only reproducibility inputs unless binary provenance, notices,
Corresponding Source obligations, and final-image SBOM requirements are
resolved separately.

The included SBOM is a partial application-manifest artifact, not a complete
container or operating-system inventory. No DOI or journal acceptance is claimed
by this release.

## Scope

Software simulation results do not establish RF conformance, commercial-UE
interoperability, voice-media quality, or RTP performance. RF operation remains
disabled by default and requires explicit local authorization, compatible
laboratory hardware, and an isolated or cabled environment.
