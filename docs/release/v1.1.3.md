# OpenLain5G v1.1.3

OpenLain5G v1.1.3 is a source-layout and operator-documentation maintenance
release. It reorganizes the application source tree and clarifies the supported
operator entry points without changing the validated software-scenario or RF
claims.

## Highlights

- Moves the backend and frontend source trees under `src/` while preserving
  package names, commands, container behavior, and validation contracts.
- Makes the operational web application the first documented operator entry
  point and the interactive CLI the second.
- Retains direct scenario commands as advanced automation interfaces.
- Synchronizes citation, CodeMeta, frontend package, OCI, Real-IMS Compose, and
  SBOM metadata at version `1.1.3`.
- Regenerates the partial CycloneDX application source-manifest SBOM for the new
  source layout.

## Verification

The repository gate passes with:

```bash
make softwarex-check
```

This executes 323 backend tests and 51 frontend tests, reports 78% backend
coverage, builds and type-checks the frontend, and validates source formats,
Compose files, profiles, versions, links, release artifacts, sanitized public
results, and sensitive-file policy.

## Evidence Scope

This maintenance release introduces no new runtime, RF, commercial-UE, or
voice-media claim. The passing 4G LTE ZMQ and 5G SA UERANSIM clean-VM summaries
remain fixed to the immutable `v1.1.0` operational evidence baseline.
Historical VoLTE and VoNR records retain their documented scopes.

The included CycloneDX artifact is a partial source-manifest SBOM. It does not
represent final telecom, IMS, database, or application image filesystems; see
[`sbom-status.md`](https://github.com/guallycanazas/Lain5G/blob/v1.1.3/docs/release/sbom-status.md)
for its exact scope and generation procedure.
