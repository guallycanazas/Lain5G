# OpenLain5G v1.1.7

OpenLain5G v1.1.7 extends the IMS validation and operator workflow.

## Highlights

- Shows IMS call setup, termination, and SIP message events in the profile-aware web logs view.
- Runs isolated synthetic SIP phone checks for registration, call progression, RTP packet exchange, teardown, and SIP message response.
- Offers a confirmation flow when another laboratory profile is active.
- Simplifies guidance and troubleshooting copy across the web interface.

## Verification

The repository verification gate is `make softwarex-check`. The tagged clean-clone workflow records five independent Ubuntu 24.04 software-scenario runs and their runner environment artifacts. The workflow result and archived runner summary are linked from this release.
