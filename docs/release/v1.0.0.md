# Lain5G-Lab v1.0.0

Released 2026-07-27.

Lain5G-Lab v1.0.0 is the first stable source release of the reproducible 4G
LTE/VoLTE and 5G SA/VoNR laboratory environment.

## Validated Software Workflows

- 4G LTE simulation: 14/14 checks passed.
- 4G VoLTE/IMS simulation: 22/22 checks passed.
- 5G SA simulation: 15/15 checks passed.
- 5G VoNR/IMS simulation: a local 25/25 run was reported, but no corresponding
  public artifact is included; the available public attempt is blocked and not
  validated.
- Repository verification: 268 backend tests, 48 frontend tests, production
  build, source/Compose/profile checks, release metadata, public-result checks,
  internal links, and sensitive-file controls passed.

## Highlights

- FastAPI and React operator workspaces for scenario preparation, operation,
  inventory, logs, validation, and run evidence.
- Guarded RF authorization, preflight, finite session duration, automatic stop,
  and emergency-stop workflows for compatible X-Series SDR profiles.
- Reproducible source selection through exact upstream commits and base-image
  digests; OS package resolution remains time-dependent.
- Sanitized public-result contracts and a partial CycloneDX application SBOM.

## Publication Boundary

This GitHub release contains source code and documentation only. It does not
publish container images or claim that existing catalog images were built from
this tag. Catalog and Real-IMS images remain pull-only reproducibility inputs
unless their binary provenance, notices, Corresponding Source obligations, and
final-image SBOM requirements are resolved separately.

The partial SBOM covers application manifests, not complete container
filesystems. Historical public results retain the release version and source
commit recorded when they were captured.

## Scope

Validated software results do not establish RF conformance, commercial-UE
interoperability, audio quality, or RTP performance. RF operation remains
disabled by default and requires explicit local authorization and compatible
laboratory hardware.
