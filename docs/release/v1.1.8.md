# OpenLain5G v1.1.8

OpenLain5G v1.1.8 refines the operator workflow and LTE X310 diagnostics.

## Highlights

- Adds `./lain5g status`, a read-only summary of the checkout, Docker, and
  running OpenLain5G containers.
- Adds stable release checks/listing, clean-checkout tag switching with a local
  backup branch, and rollback through the CLI maintenance menu.
- Adds scoped app/profile/all decommissioning. The default preserves named
  volumes, images, local configuration, run reports, source, and Docker; data
  removal requires a separate exact confirmation.
- Adds a complete-uninstall option that previews the targets and requires the
  exact phrase `BORRAR OPENLAIN5G COMPLETAMENTE`. It removes project-labeled
  volumes, OpenLain5G images, installation logs, and the checkout while
  retaining Docker and shared host dependencies.
- Adds browser-local controls for dashboard layout, accessibility, polling,
  pinned scenarios, and saved log filters.
- Keeps the 4G/5G simulation and guarded RF profiles in the web catalog while
  excluding VoLTE/VoNR signaling-only profiles from the frontend list.
- Reports LTE X310 wired-link and direct-route conditions during hardware
  checks.
- Corrects the installer dry-run assertion used by the distro bootstrap job.

## Verification

`make softwarex-check` passed: 384 backend tests, 110 frontend tests, TypeScript,
production frontend build, and the repository's source, Compose, profile,
version, link, artifact, and public-result checks.
