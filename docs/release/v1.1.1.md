# OpenLain5G v1.1.1

OpenLain5G v1.1.1 is a documentation and metadata maintenance release. It
aligns the public project identity, authorship, repository guidance, and source
manifests without changing the validated software-scenario implementations.

## Highlights

- Uses the OpenLain5G public name consistently while preserving the `lain5g`
  command, repository URL, image catalog, configuration variables, and profile
  IDs required for compatibility.
- Records Willian Roy Canazas Rosas, Manuel Ismael Prieto Tito, and Alberth
  Ronal Tamo Calla as authors, affiliated with the National University of San
  Agustin of Arequipa.
- Standardizes active technical documentation in English and retains
  `README.es.md` as the maintained Spanish overview.
- Adds contribution, security, issue-reporting, pull-request, and documentation
  navigation guidance for public collaboration.
- Removes superseded pre-release audit reports and unsupported publication or
  contact placeholders.
- Reworks installation and troubleshooting guidance around diagnostic
  categories rather than one host, address conflict, or transient error message.
- Updates source version metadata and the partial application SBOM to `1.1.1`.

## Verification

The repository gate passes with:

```bash
make softwarex-check
```

This executes 323 backend tests and 51 frontend tests, reports 78% backend
coverage, builds and type-checks the frontend, and validates source formats,
Compose files, profiles, versions, links, release artifacts, sanitized public
results, and sensitive-file policy.

## Evidence Scope

This maintenance release introduces no new runtime or RF claims. The passing
4G LTE ZMQ and 5G SA UERANSIM clean-VM summaries remain the operational evidence
from `v1.1.0`, preserved at that immutable tag. Historical VoLTE and VoNR
records retain the scopes described in the public evidence index.

The included CycloneDX artifact is a partial source-manifest SBOM. It does not
represent final telecom, IMS, database, or application image filesystems; see
[`sbom-status.md`](https://github.com/guallycanazas/Lain5G/blob/v1.1.1/docs/release/sbom-status.md)
for its exact scope and generation procedure.
