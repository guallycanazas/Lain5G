# OpenLain5G v1.1.9

OpenLain5G v1.1.9 prepares local Real IMS images during installation and adds an
optional physical SIM programming workflow for supported test cards.

## Highlights

- Adds a SIM Programmer page backed by a restricted, token-authenticated local
  PC/SC bridge. The page identifies supported sysmocom card families but writes
  only sysmoUSIM-SJS1 in this version. It verifies writes by reading card data
  back and encrypts optional credential backups in the browser. It does not
  create or synchronize subscriber records.
- Prepares PC/SC and CCID host dependencies through `./install.sh`; operations
  mode starts the local SIM bridge with the web application.
- Builds six first-party Real IMS images from the checked-out repository during
  installation and Preparation. These derived images are built locally and are
  not downloaded from or published to Docker Hub.
- Uses one versioned Real IMS image catalog for the CLI installer and web
  Preparation, and includes the operations Compose file during app shutdown.
- Adds a designed [PDF user manual](../manual/v1.1.9/OpenLain5G-User-Manual-v1.1.9.pdf)
  and its editable TeX source, covering installation, operation, evidence
  review, and safe shutdown.

## Verification

`make softwarex-check` passed locally with 389 backend tests, 112 frontend
tests, 78% backend line coverage, TypeScript, the production frontend build,
safe Compose rendering, profile checks, version and citation metadata, links,
release artifacts, public-result schemas, and sensitive-file controls. The SIM
Programmer image and all six first-party Real IMS images built locally with the
1.1.9 OCI version label. A source-manifest SBOM was regenerated for 1.1.9;
its documented scope excludes final container filesystems. GitHub-hosted
clean-clone CI has not yet run for this unpublished candidate.

Physical SIM writes, RF transmission, and X310 operation require the
corresponding physical hardware and are not established by software-only checks.
