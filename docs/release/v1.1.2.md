# OpenLain5G v1.1.2

OpenLain5G v1.1.2 is an archival metadata release prepared after enabling the
Zenodo GitHub integration. It provides a new immutable release event with
version-synchronized citation, package, OCI, Compose, and SBOM metadata.

## Highlights

- Uses `CITATION.cff` as the shared GitHub and Zenodo software citation source
  for the three confirmed authors and their institutional affiliation.
- Preserves the reviewed documentation, community guidance, public-result
  wording, and frontend test security baseline from `v1.1.1`.
- Includes Vitest `4.1.10` with zero findings across the complete locked npm
  dependency audit.
- Includes the partial CycloneDX application SBOM as a release asset.

## Verification

The repository gate passes with:

```bash
make softwarex-check
```

This executes 323 backend tests and 51 frontend tests, reports 78% backend
coverage, builds and type-checks the frontend, and validates source formats,
Compose files, profiles, versions, links, release artifacts, sanitized public
results, and sensitive-file policy.

## Evidence Scope

This archival release introduces no new runtime or RF claim. The passing 4G LTE
ZMQ and 5G SA UERANSIM clean-VM summaries remain fixed to the immutable
`v1.1.0` operational evidence baseline. Historical VoLTE and VoNR records retain
the scopes described in the public evidence index.

The included CycloneDX artifact is a partial source-manifest SBOM. It does not
represent final telecom, IMS, database, or application image filesystems; see
[`sbom-status.md`](https://github.com/guallycanazas/Lain5G/blob/v1.1.2/docs/release/sbom-status.md)
for its exact scope and generation procedure.
