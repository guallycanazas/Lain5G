# Support

Support is provided through GitHub Issues on a best-effort basis. No service
level agreement, production support, or support for RF operations is provided.

## Getting help

1. Check the root README and the relevant document under `docs/`.
2. Search existing [issues](https://github.com/guallycanazas/Lain5G/issues).
3. For a reproducible, non-sensitive problem, open a new issue with the version
   or commit, host environment, exact non-RF command, expected behavior, actual
   behavior, and sanitized logs.

Do not include secrets, real subscriber identifiers, private addresses,
operational RF settings, or authorization records. Do not run RF to gather
support information. Do not submit security-sensitive details through a public
issue. Use GitHub Private Vulnerability Reporting from the repository Security
tab without disclosing the vulnerability publicly.
