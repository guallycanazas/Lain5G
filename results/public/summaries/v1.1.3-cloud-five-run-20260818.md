# OpenLain5G v1.1.3 — five-run cloud reproduction

## Scope

This sanitized record documents five independent, clean GitHub-hosted Ubuntu 24.04 executions of the software-only LTE and 5G SA profiles. It is functional reproducibility evidence only; it makes no throughput, latency, RF, hardware, or statistical-performance claim.

## Reproduction

The workflow is manually dispatched to avoid unrequested runner consumption:

```text
Actions → “Reproduce v1.1.3 software experiments” → Run workflow
```

It checks out tag `v1.1.3`, runs each profile, records sanitized validation output, stops the profile, and uploads an evidence artifact per matrix job. The workflow definition is [reproduce-v1.1.3.yml](https://github.com/guallycanazas/Lain5G/blob/main/.github/workflows/reproduce-v1.1.3.yml).

## Safety and limitations

This record deliberately excludes credentials, subscriber identities, local addresses, host paths, protocol traces, packet captures, RF configuration, and hardware serials. These cloud runs exercise software-only profiles and do not validate USRP, physical-UE, spectrum, or IMS/VoNR hardware behavior.
